# Bright Smile Foundation – Dental Website

A responsive, animated single-page website created from the supplied Bright Smile Foundation / Balla Enterprises Trust information sheet and dental presentation.

## Open
Open `index.html` in any modern browser.

## Included
- Responsive mobile/desktop layout
- Animated hero section and counters
- Dental services and treatment filters
- Appointment request form using the supplied email address
- Click-to-call contact buttons
- Contact/footer information from the supplied material

## Important
The wording and claims are based on the supplied source material. Before publishing publicly, verify all registration, tax, address, clinical, timing, and facility claims.
